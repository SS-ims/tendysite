TROUBLESHOOTING QUICK FIXES
═══════════════════════════════════════════════════════════════════

Problem: "MySQL connection failed"
  ☐ Check MySQL is running
  ☐ Verify username/password in .env
  ☐ Verify database name is correct

Problem: "Cannot find module"
  ☐ Ran: npm install (in backend folder)
  ☐ Check node_modules folder exists

Problem: "Port 3000 already in use"
  ☐ Change SERVER_PORT in .env
  ☐ Or kill other process using port 3000

Problem: "Emails not sending"
  ☐ Verify Gmail 2FA enabled
  ☐ Verify App Password is correct (not regular password)
  ☐ Run: node backend/test-mail.js

Problem: "Admin login fails"
  ☐ Verify email/password correct
  ☐ Reset password using hash.js
  ☐ Verify JWT_SECRET in .env

Problem: "Products don't show"
  ☐ Run database.sql again
  ☐ Check: mysql -u root -p -e "SELECT * FROM tendy_db.products;"
  ☐ Check browser console (F12) for errors
